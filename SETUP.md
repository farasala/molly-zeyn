# SETUP.md — порядок работ

Этот файл для вас, не для Claude Code. Ему нужен только `CLAUDE.md`.

Главное правило: **один этап за раз, каждый заканчивается проверкой.** Не переходите
дальше, пока проверка не прошла. Просьба «сделай всё сразу» даёт неработающий проект,
который вы не сможете починить.

---

## 0. Подготовка (один раз, ~1 час)

1. **Claude Code** — установите десктопное приложение (терминал не обязателен).
2. **Аккаунты**, все бесплатные на старте:
   - GitHub — хранение кода
   - Supabase — база, аккаунты, файлы
   - Vercel — хостинг, вход через GitHub
3. **Домен** на hoster.kz — только домен, хостинг не покупайте. Vercel хостит сам.

## 1. Папка проекта

Распакуйте этот архив в папку `english-studio`. Внутри должно быть:

```
english-studio/
  CLAUDE.md                            инструкция для Claude Code
  SETUP.md                             этот файл
  schema.sql                           SQL для Supabase
  content/english-studio-content.json  весь контент курса
  audio/el/                            92 mp3, один голос
  reference/prototype.dc.html          рабочий прототип интерфейса
  reference/_ds/                       дизайн-система
  reference/courses/                   как прототип грузит контент
```

Ничего не переименовывайте — `CLAUDE.md` ссылается на эти пути.

## 2. Этап 1 — вход и регистрация

1. Откройте Claude Code в папке `english-studio`.
2. Скажите дословно:
   > Прочитай CLAUDE.md полностью. Сделай только Stage 1. Не начинай Stage 2.
3. Создайте проект в Supabase (регион — ближайший, Frankfurt или Singapore).
4. Supabase → SQL Editor → вставьте `schema.sql`, запустите.
5. Supabase → Project Settings → API: скопируйте `URL` и `anon key` в `.env.local`
   (Claude Code подскажет формат). `service_role key` — тоже туда, но он серверный.
6. Залейте код в GitHub: Claude Code сделает репозиторий и коммит.
7. Vercel → Add New Project → выберите репозиторий → в Environment Variables вставьте те же
   три ключа → Deploy. Получите адрес `*.vercel.app`.
8. Домен: Vercel → Settings → Domains → добавьте свой домен. Vercel покажет DNS-записи —
   пропишите их в панели hoster.kz. Обычно это `A @ → 76.76.21.21` и
   `CNAME www → cname.vercel-dns.com`, но **сверяйтесь с тем, что показал Vercel**.
   DNS обновляется от 15 минут до нескольких часов.

**Проверка.** Зарегистрируйтесь с телефона как студент. Откройте Supabase → Table Editor →
`profiles` на ноутбуке: студент там. Выйдите и зайдите снова — сессия держится.
Не работает — дальше не идите.

## 3. Этап 2 — контент

> Stage 1 проверен и работает. Сделай только Stage 2.

Загрузка JSON, уровни, 12 юнитов, страница урока, аудио в Supabase Storage.

**Проверка.** Все юниты и уроки открываются. Юнит 3 показывает «скоро», а не ошибку.
Аудио играет в лексике и в speaking.

## 4. Этап 3 — упражнения

> Stage 2 проверен. Сделай только Stage 3.

Движок на 7 типов заданий, проверка ответов, XP в базу.

**Проверка.** Пройдите урок на ноутбуке, выйдите, зайдите с телефона — прогресс на месте.

## 5. Этапы 4–6

По одному, тем же способом:

- **Stage 4** — кабинет студента: дашборд, банк слов, прогресс по юнитам.
  *Проверка:* цифры на дашборде, в прогрессе и в кабинете совпадают.
- **Stage 5** — кабинет преподавателя: группы, список студентов, их реальный прогресс,
  панель для урока (ответы, таймер).
  *Проверка:* результат студента с телефона виден у вас после обновления страницы.
- **Stage 6** — домашние задания: выдача, сдача, файлы, проверка. Самый долгий.
  Разбейте на три захода: выдача → сдача → проверка, каждый со своей проверкой.

## 6. Перед первыми студентами

- [ ] Демо-аккаунтов нет: ни `teacher@demo.com`, ни пароля `demo123`, ни кнопок быстрого входа.
- [ ] RLS проверен руками: заведите двух студентов и убедитесь, что один не видит данные другого.
      Файлы домашки — тоже (попробуйте открыть чужой путь).
- [ ] Бэкапы базы включены — Supabase Pro, $25/мес. На бесплатном плане бэкапов нет.
- [ ] Домен работает по HTTPS.
- [ ] Юниты 3–12 наполнены: лексика, грамматика, упражнения, speaking + записанное аудио
      тем же голосом.

## 7. Что важно знать про контент

Программа (порядок юнитов, темы, грамматика, лексические наборы) повторяет опубликованный
учебник — это законно. Но все тексты, примеры, определения и упражнения в JSON **написаны
с нуля**. Так и держите: не вставляйте туда тексты из учебника и не выкладывайте его аудио.

Озвучка — ElevenLabs, один женский британский голос (Amelia Beckett). Новые записи делайте
тем же голосом и с теми же настройками, иначе на уроке будет слышен стык. Имя файла считается
из фразы по правилу в `CLAUDE.md`, раздел «Audio».

## 8. Если что-то пошло не так

- Claude Code начал делать несколько этапов сразу — остановите и напишите:
  «Откати всё, что вне Stage N. Сделай только Stage N».
- Ошибка после деплоя, а локально всё работает — почти всегда забытые переменные окружения
  в Vercel.
- Vercel собирает старую версию — проверьте, что коммит ушёл в GitHub.
- Что-то сломалось после правки — просите Claude Code вернуть предыдущий коммит, а не
  «починить поверх».
